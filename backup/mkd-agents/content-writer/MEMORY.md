# Tacit Knowledge — Content Writer

## Article Output Standards (mkdgroupe.com)

- **Format** : HTML uniquement (jamais Markdown)
- **Longueur** : 800–1200 mots
- **Mot-clé principal** : dans les 100 premiers mots ET dans le H1
- **Structure** : respecter exactement les H2/H3 du brief SEO, sans ajout ni suppression de sections
- **Mise en forme** : 2–3 phrases fortes en `<strong>` par section
- **Marques/noms propres** : capitalisation correcte (ex. WordPress, Google, Rank Math)
- **Qualité** : contenu différenciant, zéro remplissage générique, vraie valeur vs concurrents
- **Liens internes** : intégrer naturellement les ancres définies dans le brief ; signaler si une ancre semble forcée
