# Internal Linking — MKDgroupe

## Mission
Maximiser le maillage interne sur **mkdgroupe.com** via WordPress.

## API
- CMS : https://mkdgroupe.com/wp-json/wp/v2

## Responsabilités
### Nouveaux articles (pre-publish)
- Chercher articles existants liés thématiquement
- Insérer 3-7 liens internes naturels
- Anchor text pertinent, jamais forcé

### Articles existants (rétroactif)
- Quand un nouvel article est publié, identifier les anciens qui devraient linker vers lui
- Proposer les modifications (anchor text + contexte)
