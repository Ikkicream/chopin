# API Explorer

> Source : https://docs.hetrixtools.com/api-explorer/  
> Aspiré le 2026-09-26 (WordPress REST, contenu intégral) — publié 2016-02-01, modifié 2024-08-26

You can access the API Explorer from your client area top menu:

![](https://docs.hetrixtools.com/wp-content/uploads/2024/03/image_2024-03-09_204508056.png)

Our API Explorer has been designed to be as simple and easy to understand as possible.

Begin by selecting an API Call that you wish to explore from the drop-down menu.

[![Screenshot_2](https://docs.hetrixtools.com/wp-content/uploads/2015/12/Screenshot_2.png)](https://docs.hetrixtools.com/wp-content/uploads/2015/12/Screenshot_2.png)

The following 2 fields will be automatically filled in by our system.

[![Screenshot_3](https://docs.hetrixtools.com/wp-content/uploads/2015/12/Screenshot_3.png)](https://docs.hetrixtools.com/wp-content/uploads/2015/12/Screenshot_3.png)

1. In the first field, you’ll be able to see what the API link should look like.
2. In the second field our system will fill out most of the info for you automatically, things such as your API Key or default variable values. This second field is also editable, so you can change any variables you wish to fiddle with.

It is worth mentioning that your API Key is automatically being used in your API Explorer.

You can then hit the “Go” button to explore the results of your API call right on the spot in the results box.

[![Screenshot_4](https://docs.hetrixtools.com/wp-content/uploads/2015/12/Screenshot_4.png)](https://docs.hetrixtools.com/wp-content/uploads/2015/12/Screenshot_4.png)

For every selected API call, you will receive a different instruction set below field #1.

[![Screenshot_5](https://docs.hetrixtools.com/wp-content/uploads/2015/12/Screenshot_5.png)](https://docs.hetrixtools.com/wp-content/uploads/2015/12/Screenshot_5.png)

Some API Calls will not fill in automatically all the variables in the field #2. Here’s an example.

[![Screenshot_6](https://docs.hetrixtools.com/wp-content/uploads/2015/12/Screenshot_6.png)](https://docs.hetrixtools.com/wp-content/uploads/2015/12/Screenshot_6.png)

In the example above, you’d have to fill in the IP Address and Date before the API Call can work properly, and as you can see, it gives out errors if you do not.

The results displayed in your API Explorer are identical to the ones you’d get from your API.
