In the example below, we’re asking Claude to investigate yesterday’s outage for one of our servers, since we’ve received an increased number of outage notifications for this particular server recently.

[![](https://docs.hetrixtools.com/wp-content/uploads/2026/09/4352342-675x1024.png)](https://docs.hetrixtools.com/wp-content/uploads/2026/09/4352342.png)

We’re immediately presented with a diagnosis of the incident and asked whether we should dig further to see if there’s a pattern with this specific provider, given the recent outages.

[![](https://docs.hetrixtools.com/wp-content/uploads/2026/09/32423532-526x1024.png)](https://docs.hetrixtools.com/wp-content/uploads/2026/09/32423532.png)

Digging further reveals a recurring transit issue in this location for this specific provider. So, we can now act on it based on the evidence pulled.
