# Sms Tracking

To enable SMS tracking, you have to check the toggle to activate tracking on SMS page.

![Tracking Sms](undefined)

Now you are able to send a new sms and see your tracking informations.

After few minutes ( time required to check data integrity) you’ll be able to retrieve logs on app:

[https://app.sweego.io/logs/sms](https://app.sweego.io/logs/sms)

New available status are:

- opened-proxy

- opened-human

- clicked-proxy

- clicked-human

More informations about sms:
[https://learn.sweego.io/docs/sms](https://learn.sweego.io/docs/sms)
