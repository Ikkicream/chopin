# SMS events

Source : https://learn.sweego.io/docs/webhooks/sms_events

> Webhook gives you the power to monitor events by assigning event types to url endpoints

Webhook gives you the power to monitor events by assigning event types to url endpoints

It is necessary to have at least one event

## Events

- SMS Sent

- SMS Undelivered

- Stop SMS

- SMS Click (tracking)

On webhook settings page, you will be able to see trigger sending details.
![webhook_count](undefined)

## Delivery delay

All SMS webhook events are delivered **instantly**.

If you have any questions about these events, don't hesitate to get in touch with us!
