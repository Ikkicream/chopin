# Set up sms channel

Source : https://learn.sweego.io/docs/sms/set_up_sms_channel

> To start sending sms, you’ll have to set up:

To start sending sms, you’ll have to set up:

- a [Test number](https://learn.sweego.io/docs/sms/what_is_a_test_number) (mandatory)

- a [senderId](https://learn.sweego.io/docs/sms/what_is_a_senderid) (optionnal)

Then you will be able to [send SMS through API](https://learn.sweego.io/docs/sending/how_to_send_sms_by_api).
