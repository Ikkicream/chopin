# SMTP access

Source : https://learn.sweego.io/docs/auth/smtp

> In order to send emails using our SMTP service, you will need to use your login, password and associated MTA (SMTP Server used to send your emails)

In order to send emails using our SMTP service, you will need to use your login, password and associated MTA (SMTP Server used to send your emails)

These informations can be found on The Sweego platform **Home** > **Email** > **SMTP**.

## Create SMTP access

To create your SMTP access, click on "Create SMTP Access"

From the panel, give it a name and indicate the domain(s) you will be using it with.

By default, your SMTP access will have access to all your domains.

You can restrict access to one or several domains using the “Restrict to a domain” field.

## Retrieve password

Make sure to save your password as soon as you create your SMTP access! For security reasons, we can’t show it to you again on the platform.

![domain](undefined)

## Retrieve login

You can copy your SMTP login in one click:

- As soon as you create your SMTP access

- From the list of SMTP accesses, click on the row to find your login again

![domain](undefined)

## Use

Connect to SMTP host using your provided login and password.

You can now follow this guide [to send your first email](https://learn.sweego.io/docs/sending/how_to_send_email_by_smtp)
