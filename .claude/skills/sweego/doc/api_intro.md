# Api Authentication

Source : https://learn.sweego.io/docs/api-intro

> Sweego provide an API which you can use to query data and send actions.

Sweego provide an API which you can use to query data and send actions.

To be able to use this API you will need to provide an Authorization header in your requests

We have 2 methods available :

- [Query by bearer token](/docs/auth/bearer_oauth2)

- [Query by api token](/docs/auth/api_keys)
